# Check's Auto Repair — Website

Static marketing site for Check's Auto Repair, 771 E Main St, Price, UT 84501 · (435) 630-6699.

- `index.html` — the whole site (HTML, CSS and a little vanilla JS)
- `assets/` — logo and storefront photo

No build step. On Vercel, import this repo with Framework Preset **Other** and leave Build/Output settings empty.

The quote form is a front-end mockup for now (it shows a thank-you message but doesn't send anything). Hook it to a form service (Formspree, Jotform, etc.) or a Vercel function to start capturing leads.
